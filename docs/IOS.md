## Native Auth (iOS)

Same stack as desktop Tauri:

| Concern | Implementation |
|---------|----------------|
| Login / logout / refresh | `/api/auth/native/*` against `https://songbook.lyruma.app` |
| Access token | In-memory only |
| Refresh token | `secure_*` Tauri commands → **iOS Keychain** via `keyring` (`apple-native`) |
| Fallback | Process memory only if Keychain fails — **not** localStorage |
| Session restore | Refresh token from Keychain on cold start |

**Device Keychain behaviour is not claimed validated** until a real iPhone smoke-test. Simulator CI proves the binary links; it does not replace Keychain UX testing on device.

## Signing (do not enable without approval)

For a **physical device** install you typically need:

1. Apple ID signed into Xcode
2. Signing certificate (automatic managed by Xcode for development)
3. Provisioning profile (automatic for personal team / paid team)
4. Team ID in Xcode (and optionally `bundle.iOS.developmentTeam` in `tauri.conf.json` — **do not commit secrets**)
5. Device registered (free Apple ID: limited devices / 7-day cert expiry)

### Free Apple ID (local development)

- Possible for short-lived installs onto **your** iPhone via Xcode
- Apps expire (~7 days); limited devices
- Not for TestFlight / App Store / church-wide distribution

### Paid Apple Developer Program

- Required for TestFlight, App Store, longer-lived distribution, and many CI signing setups
- **Do not purchase / enroll without explicit approval**

Never commit `.p12`, provisioning profiles, or API keys.

## What you do on your Mac (next steps after Simulator CI is green)

1. Pull `main` (includes `gen/apple` once committed).
2. Open the Xcode project under `app/src-tauri/gen/apple/*.xcodeproj` (or the `.xcworkspace` if present).
3. Select scheme for Worship Songbook.
4. Choose your **physical iPhone** as run destination (not only a simulator).
5. Signing & Capabilities → Team = your Apple ID / Developer team; Bundler ID `studio.lyruma.worshipsongbook`.
6. Trust the developer certificate on the iPhone (Settings → General → VPN & Device Management) if prompted.
7. Run from Xcode (or `npx tauri ios dev` with the device selected).
8. Smoke-test: Login, session restore, theme, language, Bands, PDF import, profile photo, logout.
